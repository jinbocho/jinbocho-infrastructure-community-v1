# Jinbocho Community — Changelog

Public changelog for the **Jinbocho Community** self-hosted bundle. Each entry
is a platform release: a coherent combination of service versions that this
repo's `docker/docker-compose.community.yml` pins and that is known to work
together.

Per-service changes are tracked in each service's own `CHANGELOG.md`
(generated by release-please — see ADR-014 in `jinbocho-docs`, private repo,
architecture rationale only, no user-facing content lives there). This file
rolls those up into the one history self-hosters actually need.

Versioning here follows SemVer independently from any single service: a
platform MAJOR/MINOR/PATCH bump reflects the significance of the bundle as a
whole (e.g. a breaking migration/upgrade step is a platform MAJOR even if
only one service actually introduced it).

Community bundle covers: `auth-service`, `catalog-service`, `api-gateway`,
`frontend`. (`ai-service` is a Pro-only addition — see the private
`jinbocho-infrastructure-pro-v1` changelog for the Pro bundle.)
