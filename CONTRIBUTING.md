# Contributing

Jinbocho is closed-source (see [LICENSE](LICENSE)) — this repo included. We
don't accept code pull requests here or in any other Jinbocho repo, so that
project ownership stays unambiguous.

## What you can do

- **Bug in an install script or compose file?** Open an issue with the
  [bug report template](.github/ISSUE_TEMPLATE/bug_report.yml).
- **Missing flag, deployment target, or behavior?** Open an issue with the
  [feature request template](.github/ISSUE_TEMPLATE/feature_request.yml).
- **Application bugs** (auth/catalog/gateway/AI/frontend): those repos are
  private — email info@jinbocho.eu.

## Security issues

Do not open a public issue for a security vulnerability (e.g. a secret leaked
by a script, an insecure default). Email info@jinbocho.eu instead.
